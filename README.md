# Source Code for Over There

This mod creates guides along the edges of your screen that point to collectible items in levels. I created this mod purely out of spite for the coin placement habits of these new creators. 

Thank me later...

## What This Mod Adds

Each collectible in a level will be given a guide. This guide contains an image of the collectible as well as an arrow that will point in the direction of that collectible.

## How Guides Work

The guides are initially transparent. As you move closer to a collectible, the guide will become opaque. Once a collectible is visible on-screen, the guide will vanish and the collectible will be marked with a red X (useful for invisible things). The guide will reappear if the collectible moves off-screen uncollected. As you move further from a collectible, the guide will become transparent again.

## Miscellaneous Features
* Option to only toggle guides when in practice mode
* Option to set maximum guide count (spam level protection)
* Customizable settings popup theme because why not
